「カボチャの魔法に誘われて」Web本ビューア試作品

1. index.html をブラウザで開くと動きます（インターネット接続不要）。
2. story.js のバッククォート `...` の中に、作品全文を貼り付けます。最初の行をタイトルとして認識します。
3. cover.png と back.png が表紙・裏表紙です。差し替える場合は同名画像を置いてください。
4. GitHub Pagesへは、このフォルダ内の5ファイルを同じ階層にアップロードしてください。
5. 本文のページ割りは「暫定的に文字数で分割」です。これはデザインと動作の確認用で、実際の印刷物のような正確なページ組ではありません。
6. GitHub Pagesで公開すると本文や画像は誰でも取得できるため、公開してよいものだけを入れてください。
