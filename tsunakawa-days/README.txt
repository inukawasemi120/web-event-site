TSUNAKAWA DAYS — イラスト本 試作品

1. フォルダ内の index.html をブラウザで開く（ローカルでそのまま動きます）。
2. イラストやコメントを変える場合は pages.js を VS Code で編集。
   image  : images/ 内の画像への相対パス
   comment: イラスト下の短いコメント（不要なら空文字）
   text   : 後から追加する少し長めの文章（不要なら空文字）
3. 新しい作品は images/ に追加し、pages.js の pages 配列に行を追加。
4. 表紙・裏表紙を差し替える場合は images/cover.jpg、images/back.jpg を入れ替えるか、pages.js のパスを変更。
5. サイトの会場からのリンク例: data-link="illustration-book/index.html"

PCでは右ページが1枚目、左ページが2枚目。スマホでは1枚ずつ表示。
イラストをクリックまたはタップすると拡大。Escキーや×で閉じられます。
公開前にスマホでレイアウトと全ページを確認してください。
